## 公開前に行うこと

1. このブランチをレビューし、公開承認後に通常の PR / Preview / merge 手順で反映する。今回 merge / deploy は実行していない。
2. 専用 stagepartners-cms の共通設定を再確認する。調査時、公開済み共通設定には `common.seo_title` がなく、コードの既定値が使われていた。一方、既存下書きには旧タイトル `STAGE PARTNERS | 株式会社ステージパートナーズ` が残っている。
3. 管理画面「設定」→共通設定の「検索結果の基本タイトル」を新タイトルへ変更し、**下書き保存のみ**を行う。他の下書き項目を無確認で一括公開しない。今回 DB は読み取りのみで、この保存は未実行。現在の公開設定のままならコード公開時に新タイトルが反映されるが、旧下書きを後で公開すると旧タイトルに戻るので、この整合を公開前チェックに含める。
4. 公開後、トップの title / og:title / twitter:title と初回表示を再確認。必要なら承認済みの範囲で Search Console の再クロールを依頼する。

Google の表示文言は自動生成され、再クロールと再処理が必要。サイト側の title を正確に変更しても、Google の検索結果の完全一致や即時更新は保証できない。
公式資料: https://developers.google.com/search/docs/appearance/title-link

ロールバックはこのコード差分の revert。DB の構造・公開データ・権限・環境変数の変更はない。下書きを整合した場合は CMS 履歴で確認できるが、旧タイトルへの復元を公開しないよう注意する。
