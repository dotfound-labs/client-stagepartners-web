# STAGE PARTNERS 管理画面 操作ガイド

管理画面はサイトURLの末尾に `/admin` を付けて開きます。
「接続設定の準備中」と表示される間はログインできません。
初回の招待メールを受け取ったら、確認画面から進み、表示された
メールアドレスが自分のものか確認してパスワードを設定してください。
パスワードをメール本文やチャットで共有する必要はありません。

## 日常の更新

1. **ホーム**から更新したい項目を選びます。
2. **施工実績**または**お知らせ**で、タイトル・説明・分類などを入力します。
3. 下書きを保存し、プレビューで内容を確認します。下書きは一般公開されません。
4. 公開権限のある担当者が公開します。公開済み内容を編集しても、
   再び公開するまでは公開版がそのまま残ります。

施工実績では、写真の説明と並び順、施工前・施工後の区分、分類、
おすすめ表示も確認してください。記事を非公開にすると公開サイトから外れます。

## 固定ページと共通情報

**ページ編集**で対象ページを選び、項目名に沿って文章・写真・リンク先を
変更します。HTMLの入力は不要です。写真の説明は画像の内容が伝わる文章にします。
検索結果のタイトル・説明も、内容に合った短い文章にしてください。
**設定**の共通情報は複数ページに反映されるため、保存前に確認します。
登録番号などの会社情報は、正式な資料で確認した値だけを入力してください。

## 画像と履歴

**画像**で画像を登録し、説明を付けます。JPEG・PNG・WebP・AVIF、10MB以下が対象です。
アップロードしただけでは一般公開されません。下書き・公開ページ・履歴で使用中の
画像は削除できません。使用中と表示された場合は無理に削除しないでください。
**履歴**から戻した内容は下書きになります。復元後もプレビューと公開操作が必要です。

## 管理者の追加と権限

**管理者権限**でメールアドレスと担当項目を指定します。
閲覧・編集・公開・削除は別々の権限です。問い合わせ閲覧と管理者管理も独立しています。
通常の担当者には必要な項目だけを付けてください。

- **招待を予約（メール送信なし）**：予約だけを保存します。
- **招待メールを送信**：その操作で実際の招待メールを送ります。宛先と権限を確認してください。

配送状況が不明な場合は、連続で取り消し・再送をせず、受信箱と配送サービスを確認します。
自分自身の権限は変更できません。最後のオーナーを無効化・降格することもできません。

## Instagramと問い合わせ

Instagram連携は設定・認可後に利用できます。取得対象は直近50件です。
Instagram由来のお知らせには出典リンクが付き、画像が取得できない場合も元の投稿を開けます。
手動で非公開にした投稿は、次の取得で勝手に再公開されません。Instagramへの投稿は行いません。

**問い合わせ**では受付内容を開き、対応状況と社内メモを更新します。
「通知サービス受付済み」はメールの配達確認ではありません。必要に応じて表示された
照合IDで通知サービスを確認してください。「未確認」は自動再送されません。
フォームが準備中の場合は、サイトに表示された電話窓口を案内します。

## 保存に失敗したとき

他の担当者による更新がある場合は、再読み込みして最新内容を確認します。
エラーが続く場合は、画面のメッセージ・操作した項目・時刻を管理担当者へ伝えてください。
秘密鍵やパスワードを添付しないでください。作業後はログアウトします。
